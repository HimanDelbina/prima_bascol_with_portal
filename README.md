# سامانه جامع و پیشرفته باسکول تحت وب (Prima Bascol)

سامانه صنعتی جامع مدیریت توزین و باسکول تحت وب بر پایه **Python & Django + PostgreSQL**، طراحی شده برای شرکت‌ها، کارخانجات و مجتمع‌های صنعتی، معدنی و بازرگانی.

این سامانه به صورت کاملاً فارسی و راست‌چین (RTL) با بهره‌گیری از تقویم جلالی (شمسی)، فونت وزیرمتن، رابط کاربری صنعتی واکنش‌گرا و سریع، **ماژول پایش هوشمند و کشف مغایرت (فاز ۱)**، گزارش‌ساز پویا با ۳۰ گزارش تخصصی، داشبورد جامع مدیران ارشد، ثبت تغییرات و ممیزی (Audit Log)، پرینت قبوض (A4، A5، POS) و معماری لایه‌بندی‌شده Service-Oriented توسعه یافته است.

---

## ۱. ویژگی‌های کلیدی سامانه

### ۱.۱. ماژول پایش هوشمند و تشخیص مغایرت (Phase 1: Smart Monitoring & Anomaly Detection)
- **موتور قانون‌محور و آماری پیشرفته (Explainable Rule-Based & Statistical Engine):**
  تحلیل خودکار رفتارها بدون مدل‌های جعبه‌سیاه، متکی بر محاسبات درون‌دیتابیسی PostgreSQL (`Avg`, `StdDev`, `Min`, `Max`, `Median`).
- **قانون ۱ - وزن خالی غیرعادی خودرو (`VEHICLE_TARE_ANOMALY`):**
  تحلیل سابقه وزن خالی خودرو با حداقل ۱۰ سابقه قبلی؛ مقایسه با میانگین متحرک، انحراف معیار ($\sigma$)، میانه و میانگین ۵ و ۱۰ سرویس آخر.
- **قانون ۲ - مغایرت وزن ارسالی و باسکول (`WEIGHT_DISCREPANCY`):**
  محاسبه اختلاف وزنی و درصدی با وزن بارنامه مبدأ به همراه تحلیل آماری رفتار و سوابق طرف حساب در متن دلیل.
- **قانون ۳ - افت غیرعادی محموله (`LOSS_ANOMALY`):**
  پایش درصد افت کالا نسبت به میانگین تاریخی محصول و تامین‌کننده و رصد اورراید دستی افت.
- **قانون ۴ - وزن خالص غیرعادی (`NET_WEIGHT_ANOMALY`):**
  تحلیل انحراف وزن خالص با Baseline سلسله‌مراتبی: ۱) خودرو + محصول ۲) خودرو ۳) محصول ۴) سراسری.
- **قانون ۵ - زمان توقف و معطلی غیرعادی (`LONG_WAITING_TIME`):**
  پایش زمان حضور خودرو بین دو توزین برای قبوض تکمیل‌شده و خودروهای باز داخل محوطه نسبت به میانگین نوع عملیات و جایگاه.
- **قانون ۶ - ریسک اصلاح دستی وزن (`WEIGHT_EDIT_ANOMALY`):**
  پایش تغییرات حساس در اوزان ثبت‌شده بر مبنای لاگ‌های `AuditLog`، دفعات ویرایش و تغییرات پس از تکمیل.
- **شاخص ریسک قبض (Risk Score 0-100):**
  تجمع وزنی هشدارهای باز بر اساس سطوح اهمیت (`INFO=0`, `LOW=5`, `MEDIUM=15`, `HIGH=30`, `CRITICAL=50`) در ۵ سطح (عادی، کم‌خطر، نیازمند بررسی، پرخطر، بحرانی) صرفاً به عنوان **ابزار پشتیبان تصمیم‌گیری (Decision Support)**.
- **توضیح‌پذیری کامل (Explainability):**
  تولید متن تحلیلی فارسی شفاف برای هر هشدار شامل مقادیر جاری، مبنا، نمونه‌های تاریخی و آستانه‌ها.
- **فرآیند رسیدگی و اقدام (Resolution Workflow):**
  امکان بررسی، اقدام/حل، یا نادیده‌گرفتن هشدار با الزام ثبت توضیح و ثبت ردپا در `AuditLog`.
- **تنظیمات پویا (Configurable Rules):**
  امکان فعال/غیرفعال‌سازی هر قانون و تغییر آستانه‌های عددی و درصدی از طریق پنل مدیریت پایش بدون نیاز به تغییر کد.
- **فرمان بررسی خودکار خودروهای باز:**
  فرمان `python manage.py check_open_tickets` جهت اسکن دوره‌ای با Cron یا Celery Beat.

### ۱.۲. توزین سریع و عملیات باسکول
- **توزین سریع با تمرکز بر UX اپراتور:**
  - فرم ورود فوق سریع با پشتیبانی از کلیدهای Enter و Tab جهت حرکت خودکار بین فیلدها.
  - ویجت گرافیکی پلاک ملی ایران با جداسازی استاندارد اجزای پلاک در دیتابیس.
  - پیش‌نمایش در لحظه (Live Preview) اوزان ناخالص، تارا، خالص، افت و وزن نهایی همراه با جداکننده هزارگان.
  - مودال‌های افزودن سریع (Quick Add) برای طرف‌حساب، راننده، خودرو و کالا بدون خروج از صفحه باسکول.
  - پشتیبانی از کلیدهای میانبر (F2: توزین جدید، F9: ثبت و ذخیره، F10: ثبت و چاپ فوری).
- **سناریوهای چندگانه توزین:**
  - پشتیبانی از سناریوی «ابتدا خالی، سپس پر» و «ابتدا پر، سپس خالی» و «ثبت مستقیم دو وزن».
  - تشخیص خودکار وزن پر (Gross = بزرگتر) و وزن خالی (Tare = کوچکتر) و وزن خالص (Net = Gross - Tare).
- **صفحه اختصاصی خودروهای در انتظار (داخل محوطه):**
  - ردیابی مدت زمان توقف هر کامیون در کارخانه با ثبت وزن اول و امکان ثبت وزن دوم با ۱ کلیک.

### ۱.۳. گزارشات و بیلان
- **گزارش‌ساز پیشرفته پویا (Advanced Report Builder):**
  - فیلتر همزمان بر اساس بازه تاریخ شمسی، ساعت، محصول، طرف‌حساب، راننده، پلاک، مبدأ، مقصد، جایگاه تخلیه، اپراتور، نوع افت و وضعیت سند.
  - کارت‌های خلاصه آماری (Summary Cards): مجموع تناژ، اوزان پر، خالی، خالص، افت، نهایی، میانگین وزن، میانگین درصد افت.
  - گروه‌بندی پویا (Group By) بر اساس روز، محصول، طرف حساب، راننده، پلاک، مبدأ، مقصد، نوع عملیات و اپراتور.
  - ۳۰ گزارش کاربردی از پیش‌تعریف‌شده برای واحدهای مدیریت، انبار، بازرگانی و کنترل کیفیت.
  - خروجی به فایل‌های **Excel (.xlsx)** راست‌چین و استایل‌بندی‌شده و **CSV (UTF-8 BOM)**.
- **داشبورد جامع مدیران ارشد (Executive Management Suite):**
  - شاخص‌های کلیدی عملکرد (KPIs) مقایسه‌ای دوره‌ای، روند ماهانه و سالانه، رادار مغایرت‌ها و مانیتورینگ TV.

### ۱.۴. امنیت، ممیزی و چاپ
- **سیستم جامع ممیزی و ردیابی تغییرات (Audit Log):**
  - ثبت خودکار کلیه رویدادهای حساس همراه با نام کاربر، IP، زمان دقیق و مقایسه مقادیر قبل و بعد (Diff).
  - عدم امکان حذف فیزیکی قبوض (استفاده از ابطال با درج دلیل اجباری).
- **چاپ رسمی قبوض باسکول:**
  - پشتیبانی از ۳ قالب رسمی: **A4 استاندارد با سربرگ**، **A5 نیم‌صفحه** و **فیش حرارتی پرینتر کوچک (POS 80mm)** همراه با محل امضای راننده، اپراتور و انبار.

## ۳. مراحل نصب و راه‌اندازی

### گام اول: فعال‌سازی محیط مجازی و نصب وابستگی‌ها
```bash
python -m venv venv
# در ویندوز:
.\venv\Scripts\activate
# در لینوکس/مک:
source venv/bin/activate

pip install -r requirements.txt
```

### گام دوم: تنظیم پایگاه داده و اعمال Migrationها
تنظیمات دیتابیس در `prima_bascol/settings.py` قرار دارد. سپس دستورات زیر را اجرا کنید:
```bash
python manage.py migrate
```

### گام سوم: اجرای سرور توسعه
```bash
python manage.py runserver 127.0.0.1:8000
```
سپس از طریق مرورگر به آدرس [http://127.0.0.1:8000/](http://127.0.0.1:8000/) مراجعه فرمایید.

## ۵. کاربران و نقش‌های پیش‌فرض سیستم

| نام کاربری | نقش کاربری | دسترسی‌ها |
| :--- | :--- | :--- |
| `admin` | **Super Admin (مدیر ارشد)** | دسترسی نامحدود به تمامی بخش‌ها، تنظیمات پایش، مدیریت کاربران و لاگ‌ها |
| `manager` | **مدیر باسکول (Weighbridge Manager)** | مدیریت پایش هوشمند، اقدام روی هشدارها، ویرایش اوزان، ابطال اسناد، گزارش‌گیری |
| `operator1` / `operator2` | **اپراتور باسکول (Operator)** | ثبت وزن اول و دوم، مشاهده هشدارهای آنی، چاپ قبوض |
| `reporter` | **مدیر گزارشات (Report Manager)** | دسترسی کامل به گزارش‌ساز پویا و ۳۰ گزارش تخصصی و تحلیلی |
| `viewer` | **مشاهده‌گر (Viewer)** | مشاهده داشبورد و سوابق بدون امکان تغییر در اطلاعات |

## ۶. ساختار معماری پروژه

```
prima_bascol/
├── prima_bascol/          # پیکربندی ریشه جنگو (settings, urls, wsgi, asgi)
├── core/                  # هسته: تنظیمات سیستم، توابع تاریخ شمسی، Backup، WeightProvider
├── accounts/              # مدیریت کاربران، سطوح دسترسی و نقش‌ها
├── masterdata/            # اطلاعات پایه (محصولات، طرف‌ها، رانندگان، خودروها، پلاک‌ها...)
├── weighbridge/           # عملیات باسکول: ثبت توزین، محاسبات وزن، قبوض، چاپ
│   ├── services.py        # محاسبات خالص، تارا، ناخالص، افت و شماره سریال
│   └── views.py           # فرم‌های توزین و یکپارچه‌سازی با موتور پایش
├── monitoring/            # ماژول پایش هوشمند و کشف مغایرت (فاز ۱)
│   ├── models.py          # مدل‌های MonitoringAlert و MonitoringRuleConfig
│   ├── selectors/         # کوئری‌های آماری و تجمیعی دیتابیس PostgreSQL
│   ├── services/          # سرویس‌های تحلیل ۶ گانه و موتور AnomalyDetectionEngine
│   ├── management/        # فرمان‌های بررسی دوره‌ای (check_open_tickets)
│   ├── forms.py           # فرم‌های تنظیم آستانه‌ها و اقدام روی هشدار
│   ├── exports.py         # خروجی‌های Excel و CSV هشدارهای پایش
│   ├── templatetags/      # برچسب‌های شدت هشدار، شاخص ریسک و وضعیت
│   └── tests/             # آزمون‌های واحد جامع سناریوهای پایش
├── reports/               # گزارش‌ساز پیشرفته، ۳۰ گزارش آماده، خروجی‌های Excel و CSV
├── audit/                 # ماژول ثبت تغییرات و ممیزی (Audit Log)
├── dashboard/             # داشبورد عملیاتی و کنترل توزین
├── management/            # داشبورد جامع مدیران ارشد و هوش تجاری
├── static/                # استایل‌های صنعتی، ویجت پلاک، اسکریپت‌های توزین زنده
└── templates/             # قالب‌های HTML کاملاً فارسی و واکنش‌گرا
```

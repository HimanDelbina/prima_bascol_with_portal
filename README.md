# سامانه جامع و پیشرفته باسکول تحت وب (Prima Bascol)

سامانه صنعتی جامع مدیریت توزین و باسکول تحت وب بر پایه **Python & Django**، طراحی شده برای شرکت‌ها و مجتمع‌های صنعتی، معدنی و بازرگانی.

این سامانه به صورت کاملاً فارسی و راست‌چین (RTL) با بهره‌گیری از تقویم جلالی (شمسی)، فونت وزیرمتن، رابط کاربری صنعتی واکنش‌گرا و سریع، گزارش‌ساز پویا با ۳۰ گزارش تخصصی، ثبات تغییرات (Audit Log)، پرینت قبوض (A4، A5، POS) و معماری لایه‌بندی‌شده با قابلیت ارتقا به اتصال سخت‌افزاری دیجیتال توسعه یافته است.

---

## ۱. ویژگی‌های کلیدی سامانه

- **توزین سریع با تمرکز بر UX اپراتور:**
  - فرم ورود فوق سریع با پشتیبانی از کلیدهای Enter و Tab جهت حرکت خودکار بین فیلدها.
  - ویجت گرافیکی پلاک ملی ایران با جداسازی استاندارد اجزای پلاک در دیتابیس.
  - پیش‌نمایش در لحظه (Live Preview) اوزان ناخالص، تارا، خالص، افت و وزن نهایی همراه با جداکننده هزارگان.
  - مودال‌های افزودن سریع (Quick Add) برای طرف‌حساب، راننده، خودرو و کالا بدون خروج از صفحه باسکول.
  - پشتیبانی از کلیدهای میانبر (F2: توزین جدید، F9: ثبت و ذخیره، F10: ثبت و چاپ فوری).
- **سناریوهای چندگانه توزین:**
  - پشتیبانی از سناریوی «ابتدا خالی، سپس پر» و «ابتدا پر، سپس خالی» و «ثبت مستقیم دو وزن».
  - تشخیص خودکار وزن پر (Gross = بزرگتر) و وزن خالی (Tare = کوچکتر) و وزن خالص (Net = Gross - Tare).
- **محاسبات پیشرفته افت و مغایرت:**
  - انواع افت (رطوبت، ناخالصی، خاک، کسری وزن، توافقی).
  - محاسبه خودکار وزن افت بر اساس درصد یا اورراید دستی همراه با درج اجباری دلیل و ثبت لاگ.
  - مقایسه وزن خالص باسکول با وزن ارسالی در بارنامه مبدأ و محاسبه اختلاف وزنی و درصدی.
  - هشدار بصری آنی در صورت فراتر رفتن انحراف وزن از سقف مجاز استاندارد کالا یا سیستم.
- **صفحه اختصاصی «خودروهای در انتظار تکمیل باسکول (داخل محوطه)»:**
  - ردیابی مدت زمان توقف هر کامیون در کارخانه با ثبت وزن اول و امکان ثبت وزن دوم با ۱ کلیک.
- **گزارش‌ساز پیشرفته پویا (Advanced Report Builder):**
  - فیلتر همزمان بر اساس بازه تاریخ شمسی، ساعت، محصول، طرف‌حساب، راننده، پلاک، مبدأ، مقصد، جایگاه تخلیه، اپراتور، نوع افت، انحرافات وزنی و وضعیت سند.
  - کارت‌های خلاصه آماری (Summary Cards): مجموع کل تناژ، مجموع اوزان پر، خالی، خالص، افت، نهایی، میانگین وزن، میانگین درصد افت، حداقل و حداکثر وزن.
  - گروه‌بندی پویا (Group By) بر اساس روز، محصول، طرف حساب، راننده، پلاک، مبدأ، مقصد، نوع عملیات و اپراتور.
  - ۳۰ گزارش کاربردی از پیش‌تعریف‌شده برای واحدهای مدیریت، انبار، بازرگانی و کنترل کیفیت.
  - خروجی به فایل‌های **Excel (.xlsx)** راست‌چین و استایل‌بندی‌شده، **CSV (UTF-8 BOM)** و پیش‌نمایش چاپی.
- **چاپ رسمی قبوض باسکول:**
  - پشتیبانی از ۳ قالب رسمی: **A4 استاندارد با سربرگ**، **A5 نیم‌صفحه** و **فیش حرارتی پرینتر کوچک (POS 80mm)** همراه با محل امضای راننده، اپراتور و انبار.
- **سیستم جامع ممیزی و ردیابی تغییرات (Audit Log):**
  - ثبت خودکار کلیه رویدادهای حساس (ایجاد، ویرایش اوزان، ابطال، چاپ، تغییر وضعیت) همراه با نام کاربر، IP، زمان دقیق و مقایسه مقادیر قبل و بعد (Diff).
  - عدم امکان حذف فیزیکی قبوض (استفاده از ابطال با درج دلیل اجباری).
- **پشتیبان‌گیری و بازیابی پایگاه داده:**
  - دانلود آنلاین فایل Backup پایگاه داده SQLite و امکان بازیابی مطمئن با نسخه پشتیبان اضطراری خودکار.
- **آمادگی جهت اتصال به باسکول دیجیتال (WeightProvider Abstraction):**
  - جداسازی کامل منطق دریافت وزن از فرم‌ها و مدل‌ها. در فاز فعلی `ManualWeightProvider` فعال است و در آینده می‌توان به سادگی درایورهای `Serial / RS232 / TCP-IP / REST API` را متصل نمود.

## ۳. مراحل نصب و راه‌اندازی گام‌به‌گام

### گام اول: ورود به پوشه پروژه و ساخت Virtual Environment
```bash
cd prima_bascol
python -m venv venv
```

### گام دوم: فعال‌سازی محیط مجازی
- **در ویندوز (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
- **در ویندوز (CMD):**
  ```cmd
  venv\Scripts\activate.bat
  ```
- **در لینوکس / مک:**
  ```bash
  source venv/bin/activate
  ```

### گام سوم: نصب وابستگی‌ها (Requirements)
```bash
pip install -r requirements.txt
```

### گام چهارم: اعمال Migrationها روی پایگاه داده
```bash
python manage.py migrate
```

### گام پنجم: بارگذاری داده‌های اولیه و تستی (Seed Data)
با اجرای دستور زیر، تنظیمات سیستم، محصولات (آهن اسفنجی، گندله و...)، طرف‌های حساب، رانندگان، خودروها و پلاک‌های نمونه، و ۶ کاربر با نقش‌های مختلف ایجاد می‌شوند:
```bash
python manage.py seed_data
```

### گام ششم: اجرای سرور توسعه
برای اجرای سامانه روی سیستم لوکال:
```bash
python manage.py runserver
```

برای اجرای سامانه **روی شبکه داخلی شرکت (قابل دسترس برای تمامی کلاینت‌ها و تبلت‌ها در شبکه LAN)**:
```bash
python manage.py runserver 0.0.0.0:8000
```
سپس از طریق مرورگر به آدرس `http://localhost:8000` یا آی‌پی سیستم در شبکه (مثلاً `http://192.168.1.100:8000`) مراجعه فرمایید.

## ۷. ساختار معماری پروژه

```
prima_bascol/
├── prima_bascol/          # پیکربندی ریشه جنگو (settings, urls, wsgi, asgi)
├── core/                  # هسته: تنظیمات سیستم، توابع تاریخ شمسی، Backup، WeightProvider
│   ├── jalali.py          # توابع تبدیل و فرمت تاریخ شمسی
│   ├── weight_provider.py # معماری دریافت وزن و تفکیک لایه سخت‌افزار
│   ├── backup.py          # سرویس پشتیبان‌گیری و بازیابی SQLite
│   ├── middleware.py      # کپچر کردن User و IP جهت ثبت در لاگ
│   └── templatetags/      # فیلترهای قالب (jdate, weight_fmt, pdigits, status_badge)
├── accounts/              # مدیریت کاربران، سطوح دسترسی و پروفایل
├── masterdata/            # مدیریت اطلاعات پایه (محصولات، طرف‌ها، رانندگان، خودروها، پلاک‌ها...)
├── weighbridge/           # قلب سیستم: ثبت توزین، محاسبات وزن، قبوض، چاپ
│   ├── services.py        # TicketCalculationService & SerialNumberService
│   └── forms.py           # فرم‌های اعتبارسنجی توزین و اورراید
├── reports/               # گزارش‌ساز پیشرفته، ۳۰ گزارش آماده، خروجی‌های Excel و CSV
│   ├── services.py        # موتور فیلتر سرور و Group By پویا
│   ├── preset_reports.py  # تعاریف ۳۰ گزارش آماده
│   └── exports.py         # موتور تولید اکسل با openpyxl و CSV
├── audit/                 # ماژول ثبت تغییرات و ممیزی (Audit Log)
├── dashboard/             # داشبورد مدیریتی و نمودارهای تحلیلی Chart.js
├── static/                # استایل‌های صنعتی، ویجت پلاک، اسکریپت‌های توزین زنده
└── templates/             # قالب‌های HTML کاملاً فارسی و واکنش‌گرا
```
